================================================================================
  Progress Bar Plus - Editor v2.0.0
  Workspace & File Organization Guide
  Repository: https://github.com/Walter-Correa/Progress-Bar-Plus
================================================================================

This directory ("scriptfiles/Progress Bars/") stores all projects, reusable bar
templates, imported scripts, and exported Pawn source code generated by the
Progress Bar Plus in-game Editor.

--------------------------------------------------------------------------------
  DIRECTORY STRUCTURE
--------------------------------------------------------------------------------

  Progress Bars/
  |-- Projects/      Multi-bar workspace projects (.pbp) and "_index.lst"
  |-- Templates/     Reusable single-bar style presets (.pbt) and "_index.lst"
  |-- Exports/       Generated production-ready Pawn code (.pwn, .inc, .txt)
  |-- Imports/       Drop external .pbp projects or .pwn/.txt code here
  +-- README.txt     This quick-reference guide

--------------------------------------------------------------------------------
  HOW TO USE EACH FOLDER
--------------------------------------------------------------------------------

1. Projects/ (.pbp)
   - Every saved project stores up to 20 progress bar layers, including their
     variable names, positions, dimensions, styles (Bar / Ring / Circle),
     colors, borders, radial segment settings, auto-fill animations, and
     blinking alert configurations.
   - "_index.lst" tracks saved projects so they appear automatically inside
     the in-game Project Browser (PROJECT -> Open Project or /pbload).

2. Templates/ (.pbt)
   - Single-bar presets that can be spawned into any project in one click via
     "+ CREATE -> From Template".
   - You can save any custom bar you design as a new reusable template via
     "LAYERS -> Layer Actions -> Save Layer as Template".

3. Exports/ (.pwn / .inc / .txt)
   - Generated code files appear here whenever you click "EXPORT" or run
     "/pbexport" in-game:
       * <Project>.pwn      Full Gamemode / Filterscript integration script
       * <Project>.inc      Standalone plug-and-play modular include header
       * <Project>_raw.txt  Concise raw CreatePlayerProgressBar(...) snippet

4. Imports/ (.pbp / .pwn / .inc / .txt)
   - Place external ".pbp" project files or existing ".pwn"/".txt" scripts
     containing CreatePlayerProgressBar(...) calls into this folder.
   - In-game, open "PROJECT -> Import Wizard" (or type "/pbimport") to:
       * Open or Merge an external ".pbp" project file.
       * Parse and reconstruct bars from raw Pawn source code files (supports
         both Progress Bar Plus and legacy progress2 syntax!).
       * Or paste a single CreatePlayerProgressBar(...) line directly into an
         in-game dialog without creating a file.
